# Roadmap V1

## Estado actual

1. Estructura nativa de Codex creada.
2. Skills base del ciclo completo disponibles.
3. Comandos slash base definidos, incluyendo scaffolding.
4. Templates frontend React+Tailwind y Angular+Tailwind agregados.
5. Templates backend Fastify+Prisma+Postgres y NestJS+Prisma+Postgres agregados.
6. Scaffolding por preset/tipo (`rapid|robust` + `frontend|backend|fullstack`) habilitado.
7. Pipeline CI de templates en GitHub Actions agregado.
8. Pipeline de release docs a GitHub Pages agregado.
9. Portal docs inicial listo.
10. Stacks backend adicionales listos: FastAPI, Go, Java.
11. Plantillas cloud IaC listas: AWS/GCP/Azure.
12. Modulos auth/rbac/refresh + pagos + mensajeria en templates backend.
13. Migraciones/seed/tests base por backend incluidas.
14. CI/CD por template con preview deploy de PR via GHCR.
15. Verticales base: saas/ecommerce/marketplace/ai-heavy.

## Siguiente bloque recomendado

1. Agregar ejemplos funcionales por vertical con dominio real.
2. Endurecer e2e contra BD real para todos los templates backend.
3. Agregar integraciones MCP concretas por proveedor.
4. Expandir deploy preview a proveedor cloud real opcional (no solo image preview).
5. Agregar catalogo de checklists por tipo de proyecto.

## V2 objetivo

- Version en ingles.
- Skills avanzadas por vertical.
- Integracion empresarial (compliance y auditoria).
