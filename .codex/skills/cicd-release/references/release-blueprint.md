# Release Blueprint

## Pre-release

1. Validar calidad y seguridad.
2. Confirmar migraciones.
3. Confirmar plan de rollback.

## Release

1. Ejecutar deploy con estrategia definida.
2. Monitorear metricas de error y latencia.
3. Habilitar feature flags gradualmente si aplica.

## Post-release

1. Verificar SLO inicial.
2. Registrar incidentes y acciones.
3. Cerrar release con retro corta.
