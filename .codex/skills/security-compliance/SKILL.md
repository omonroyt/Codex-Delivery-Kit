# Security Compliance

Aplicar seguridad por diseno y por operacion.

## Checklist minimo

1. Gestion de secretos
2. Control de acceso
3. Validacion de entrada/salida
4. Registro de eventos de seguridad
5. Plan de respuesta a incidentes

## Regla

Si hay datos sensibles, elevar prioridad de seguridad sobre velocidad.
