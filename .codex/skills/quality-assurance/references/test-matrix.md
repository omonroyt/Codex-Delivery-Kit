# Test Matrix

## Niveles

1. Unit: logica pura y funciones criticas.
2. Integration: contratos entre modulos.
3. E2E: flujos de usuario de alto impacto.

## Priorizacion

- P0: auth, pagos, permisos, datos sensibles.
- P1: flujos core de negocio.
- P2: mejoras de UX y contenido.

## Evidencia minima

- resultado de comandos de test
- cobertura de rutas criticas
- defectos abiertos y severidad
