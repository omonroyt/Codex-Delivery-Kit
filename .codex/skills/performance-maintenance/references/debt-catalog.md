# Debt Catalog

## Tipos de deuda

1. Codigo: complejidad, duplicacion, acoplamiento.
2. Datos: esquemas sin indices, migraciones pendientes.
3. Operacion: alertas ruidosas, runbooks incompletos.
4. Producto: decisiones temporales no revisadas.

## Priorizacion

- impacto en cliente
- riesgo tecnico
- costo de no resolver

## Cadencia

- revisar deuda en cada sprint
- reservar capacidad fija para reduccion de deuda
