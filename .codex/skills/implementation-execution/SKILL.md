# Implementation Execution

Construir por pasos pequenos y verificables.

## Protocolo

1. Confirmar alcance del incremento.
2. Implementar cambio minimo util.
3. Ejecutar validaciones locales.
4. Reportar impacto y pendientes.

## Reglas

- No mezclar refactor grande con nueva feature sin acuerdo.
- Mantener cambios coherentes por modulo.
- Documentar decisiones no obvias.
