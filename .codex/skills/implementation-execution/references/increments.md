# Increment Strategy

## Tamano recomendado

- Cambios de 1 objetivo funcional por iteracion.
- Si excede, dividir por capas o por flujo de usuario.

## Secuencia recomendada

1. Contrato
2. Logica
3. Integracion
4. UI (si aplica)
5. Tests

## Cierre de incremento

- evidencia de pruebas
- impacto en riesgo
- siguiente incremento propuesto
